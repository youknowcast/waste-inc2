# Waste Inc. II — 産廃カードローグライク

[youknowcast/waste-inc](https://github.com/youknowcast/waste-inc) の世界観をそのままに、Balatro の骨格で作った産業廃棄物のブラウザゲーム。1 ランは **3 営業日 × 3 便 = 9 ブラインド** で、およそ **10〜15 分**で決着します。

## ▶ 遊ぶ

**https://youknowcast.github.io/waste-inc2/**

インストール不要・ブラウザだけで遊べます。

## ゲームの流れ

1. **タイトル** — 「はじめる」で 1 ラン開始
2. **元請の選択** — その日の 3 便（午前便・午後便・締切）を確認し、次の便を開始
3. **盤面** — 手札から 1〜5 枚選んで「搬入」し、役を作って売上を伸ばす
4. **精算** — 突破すれば報酬・手数ボーナス・利息を受け取る
5. **ショップ** — ジョーカーを購入・売却・リロールして次の便へ
6. **リザルト** — 3 日目の締切を突破するとランク（B/A/S）が表示される

各便で目標金額に届かず手札を使い切ると、その場で**解散**（敗北）です。

## 得点

```
売上 = 重さ(t) × 単価(万円/t)   ← 表示は万円
```

- **重さ** = 役の基礎重さ + 役を構成するカードのランク値の合計 + ジョーカー補正
- **単価** = 役の基礎単価 + ジョーカー補正
- ランク値：2〜10 は同値、J/Q/K = 10、**A = 11**
- 重さに乗るのは役を構成したカードのみ。ジョーカーの枚数条件は「出した枚数（1〜5）」で数える
- 乗算補正は最後にまとめて掛け算。1 回の搬入ごとに売上を切り捨てて合算する

## カード

**52 枚** = 4 分類 × 13 ランク。品目名は実在の産業廃棄物がそのまま入っています。

| 分類 | マーク | 色 |
|---|---|---|
| 建廃 | 🧱 | テラコッタ |
| 汚泥 | 💧 | オリーブ |
| 資源 | ♻️ | 青 |
| 特管 | ☣️ | 紫 |

4 分類は採点上まったく等価です。強弱はジョーカー側に寄せています。

## ジョーカー

車両・許可・分類シナジー・経済系など**20 枚**が存在し、最大 **5 枠**まで所持できます。各便の突破後に開くショップで購入できます。同じジョーカーを複数所持可能です。

主なカテゴリ：

- 🚚 **積載** — 重さを加算・倍化する車両系
- 📋 **交渉・許可** — 単価を上げる許可・契約系
- 🧱💧♻️☣️ **分類シナジー** — 特定の分類が多い役を強化
- 💰 **経済・一発系** — 利息・売却・リロール補正や締切ボーナス

詳細は設計書の「ジョーカー」セクションを参照してください。

## 元請（締切）の縛り

各日の締切は元請案件で、日ごとに縛りがかかります。

| 日 | 元請 | 縛り |
|---|---|---|
| 1 日目 | 抜き打ち立入検査 | 特管のカードは採点されない（役の成立には数えるが、重さも単価も乗らない） |
| 2 日目 | 元請の値切り | 役の基礎単価が半減する（端数は切り上げ） |
| 3 日目 | 大雨警報 | 手札が 7 枚に減る。目標は 5000 万円 |

## システム

- **1 ラン = 9 ブラインド**: 3 営業日 × 午前便・午後便・締切。目標金額は 300 万円から最終 5000 万円まで段階的に上がる
- **各便**: 手札 8 枚（大雨警報時は 7 枚）、**搬入 4 回・捨て札 3 回**まで
- **所持金**: 開始 4 万円。突破報酬は午前便 3 万円 / 午後便 4 万円 / 締切 5 万円
- **手数ボーナス**: 使い残した搬入 1 回につき +1 万円
- **利息**: 所持金 5 万円ごとに +1 万円（上限 +5 万円）
- **ショップ**: 各便突破後に開く。ジョーカー 2 枚を陳列、レア度で価格と出現率が変わる。リロールは 3 万円から 1 回ごとに +1 万円
- **シード**: `?seed=<値>` でランを再現・共有できます。同じシードは同じデッキ順・ショップ品揃えになります
- **効果音**: WebAudio で合成。音源ファイルは一切ありません。右上の 🔊 で ON/OFF を切り替え、設定は localStorage に保存されます
- **アセットなし**: 画像・音声ファイルはなく、カードや UI は CSS と絵文字で描画されます

## 開発

```bash
npm run test    # Vitest（tests/ のユニットテスト）
npm run lint    # Biome
npm run typecheck  # TypeScript の型チェック
npm run build   # 型チェック + Vite 本番ビルド（dist/）
```

- `src/game/` — ゲームロジック（DOM 非依存の純粋関数・シード可能 PRNG）
- `src/ui/` — Vue コンポーネントと単一のリアクティブ store（状態 → DOM）・効果音
- `src/data/` — 静的データ（52 品目・20 ジョーカー・9 便）
- 設計: [docs/superpowers/specs/2026-10-16-waste-inc2-design.md](docs/superpowers/specs/2026-10-16-waste-inc2-design.md)
- `main` への push で GitHub Actions が lint / test / build を実行し、GitHub Pages へ自動デプロイされます
