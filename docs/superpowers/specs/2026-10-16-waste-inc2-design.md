# waste-inc2 設計書（アルファ版）

2026-10-16

## 意図

[youknowcast/waste-inc](https://github.com/youknowcast/waste-inc)（産廃配車ローグライク）の世界観をそのままに、
**Balatro の骨格を素直に fork した、産業廃棄物のブラウザゲーム**を作る。

前作は「配車」というリソース配分パズルだった。今作は遊びの芯を Balatro に置き換える。
手札から5枚まで選んで役を作り、**重さ × 単価 = 売上** を弾けさせる。
ジョーカーは車両・許可・人脈・処分場契約になり、役と噛み合ったときに数字が跳ねる。

アルファの目的は完成度ではなく、**遊べるものを最短で出して、実際に触って面白い／面白くないを掴むこと**。
1プレイ 10〜15分で決着する短いランにして、何度も回せるようにする。

## ゴール / 非ゴール / アンチゴール

### ゴール
- ブラウザだけで遊べる（インストール不要・配信は GitHub Pages）
- 1プレイ 10〜15分で決着する（3営業日）
- 「役 × ジョーカーが噛み合って売上が弾ける」瞬間が気持ちいい
- 産廃の品目名が実在のもので、業界の人がニヤリとする
- 9ブラインド × ショップという Balatro のリズムがそのまま成立している

### 非ゴール（アルファでは作らない）
- 画像アセットの制作（見た目はコード生成の SVG / CSS のみ）。**BGM と音源ファイルも入れない**（効果音は WebAudio で合成する）
- 消費アイテム（タロット／プラネット／スペクトル相当）
- ブースターパック、バウチャー、シール、エディション、カード強化
- エンドレスモード、難易度（ステーク）選択
- オンライン要素、クラウド保存

### アンチゴール（こうなったら失敗）
- 産廃用語の解説が延々と出て、遊びに入れない。用語は品目名と元請の名前までで止める
- 1プレイが30分を超える
- 数字だけが大きくて、プレイヤーの判断が発生しない（＝カードを選ぶ意味がない）

## 制約

- **TypeScript + Vite + Vitest + Biome**（前作 `waste-inc` と同じ流儀を持ち込む）
- ゲームロジックは **DOM 非依存の純粋関数**。`src/game/` に置き、シード可能な PRNG を使う
- 描画は **状態 → HTML 文字列**。`src/ui/` に置く（前作と同じ。アルファでは十分速い）
- 静的なデータ（品目・ジョーカー・元請）は `src/data/`
- 乱数は `?seed=<値>` で固定でき、同じランを再現・共有できる
- アセットはコード生成のみ。分類の色と絵文字、CSS で表現する
- 効果音は **WebAudio で合成**する（前作と同じ。音源ファイルを持たない）

## 遊びの構造

1営業日 = 3便。これを3日 = 3アンテ = **9ブラインド**。

```
1日目  午前便 小口収集 → 午後便 量産現場 → 締切 抜き打ち立入検査
2日目  午前便 解体現場 → 午後便 再開発現場 → 締切 元請の値切り
3日目  午前便 大型土木 → 午後便 最終処分場搬入 → 締切 大雨警報（最終）
```

各便の中身（Balatro のブラインド単位に相当）:

- 手札 8枚。1回に 1〜5枚まで出して役を作る
- **手札 4回・捨て札 3回**まで
- その便の目標金額を、4回以内の累計売上で超えたら突破
- 使い切って届かなければ **即敗北（その場で解散）**
- 突破したら精算してショップへ

## 得点

```
売上 = 重さ(t) × 単価(万円/t)        ← 表示は万円
```

- **重さ** = 役の基礎重さ + **役を構成するカード**のランク値の合計 + ジョーカー補正
- **単価** = 役の基礎単価 + ジョーカー補正

ランク値は 2〜10 が同値、J/Q/K = 10、**A = 11**。= 積載重量（t）。

**重さに乗るのは役を構成したカードだけ**（Balatro と同じ。5枚出しても、役に使われていない3枚は重さを持たない）。
ただしジョーカーの「3枚以上出したら」「5枚出したら」といった**枚数の条件は、出した枚数（1〜5）で数える**。
役に使われなかったカードも数える。

**乗算補正は最後にまとめて掛け算で合成する**（×1.25 と ×1.5 が効いていれば ×1.875）。
単価は小数のまま扱い、**売上は1回の搬入ごとに切り捨てて、その合計を目標と比べる**。

## 元請（締切）の縛り

締切だけは元請案件で、日ごとに違う縛りがかかる。

| 日 | 元請 | 縛り |
|---|---|---|
| 1日目 | 抜き打ち立入検査 | **特管のカードは採点されない**（役の成立には数えるが、重さも単価も乗らない） |
| 2日目 | 元請の値切り | **役の基礎単価が半減**（端数は切り上げ） |
| 3日目 | 大雨警報 | **手札が7枚に減る**。目標は 5000万円 |

## お金

- 開始資金 **4万円**
- 突破報酬: 午前便 3万円 / 午後便 4万円 / 締切 5万円
- 手数ボーナス: 使い残した手札1回につき **+1万円**
- 利息: 所持金5万円ごとに **+1万円**（上限 +5万円）
- ショップは **各便の突破後**（1ランに9回）
  - ジョーカーを2枚並べる。価格はレア度で 4 / 6 / 8万円
  - 品揃えはレア度で抽選する: COMMON 60% / UNCOMMON 30% / RARE 10%。同じショップに同じものが2枚並ぶことはない
  - プールは減らない。**同じジョーカーを複数所持できる**（5枚重なれば5回効く。Balatro と同じ）
  - リロールは 3万円から、1回ごとに +1万円
  - 枠が埋まっていれば、先に売って空ける（売却額 = 購入額の半分）
  - ごく稀に、レア度抽選の枠外で **不法投棄の噂** が出る

## 画面

すべてブラウザ1画面。状態は

```
タイトル → 元請の選択 → 盤面（手札を選ぶ → 搬入 → 採点） → 精算 → ショップ → 次の便 …
                                                                → 3日目の締切を突破 → リザルト
```

「元請の選択」は、その日の3便（午前便・午後便・締切）を一覧して、**次に挑む便を選んで開始する画面**。
ラン開始時にデッキや初期ジョーカーを選ぶような分岐は入れない（全員が同じ52枚で始める）。

**盤面は簡素に保つ**（実際に作って確認済みの形）:

- 上段: 左に「3日目 午後便／残り手札・捨て札」、右に **目標金額を大きく**
- その下に **売上バー**（現在の売上 / あと何万円）
- 中央: 普段は静か。**搬入した瞬間に「重さ × 単価 = 売上」が大きく弾ける**
- 下段: 手札8枚（大きめのカード）、左下に **ジョーカー5枠（名前＋効果の数字を常時表示）**、右下に「搬入／捨てる」
- 採点時、効いたジョーカーの名前が数字の下に並ぶ（何が効いたかが分かる）

**モックアップは `.superpowers/brainstorm/` に保存済み**（`card-anatomy.html` / `jokers.html` / `board-v3.html`）。
これが実装の見た目の基準。

## リザルト

- 総売上、残金、突破した便、取得ジョーカー
- 総売上でランク付け（B / A / S の3段で十分）
- 前作同様、シードを表示して同じランに再挑戦できるようにする

## 音

**最小限の効果音だけ入れる。BGM と音源ファイルは入れない。**前作と同じく WebAudio で合成する。

鳴らすのは、手触りに効くところだけ:

| 場面 | 音 |
|---|---|
| カードを配る | 軽い「シャッ」。配る枚数だけ少しずつずらして鳴らす |
| カードを選ぶ／外す | ごく短いクリック |
| 捨てる | 「シュッ」と流れる音 |
| 搬入して採点 | **重さ → 単価 → 売上 の3段**で鳴らす。売上が確定するところが一番大きい |
| 目標を突破 | 明るく上がる音 |
| 未達で解散 | 下がる音 |
| ショップで買う／リロール | 短いチャイム／コイン |

- 派手な演出は入れない。音は短く、連打しても耳につかない長さにする
- 画面の右上に 🔊 で ON/OFF。設定は localStorage に残す
- ブラウザの都合で、最初の操作までは音を鳴らせない。最初のクリックで解錠する

## 実装の分け方

```
src/
  game/     cards(デッキ生成・シャッフル) hands(役判定) score(採点) jokers(効果適用)
            blinds(目標・縛り) shop(品揃え) run(ラン進行) rng(シード可能PRNG)
  data/     items(52品目) jokers(20枚) blinds(9便+元請3)
  ui/       render(状態→HTML) style(CSS) card(カード描画) sound(WebAudioで効果音を合成)
```

`src/game/` は DOM に一切触れない。ここに Vitest を当てる。

## 私の判断で決めたところ

聞かずに決めた部分。気になるものがあれば言ってほしい。

1. **役の基礎値は Balatro の数字をそのまま流用**（呼称だけ差し替え）。実績のあるバランスを動かさないため
2. **金額のスケール**: 単価 = 万円/t、目標 = 300万円〜5000万円。前作の「10営業日」は3営業日に短縮
3. **4分類は等価**（本人の選択）。らしさはジョーカー側に寄せた
4. **元請の縛りの中身**（上記3つ）、**報酬・利息・リロールの金額**
5. **音は最小限の効果音だけ**（下記）。派手な演出は入れず、手触りのところだけ鳴らす
6. **タイトルは仮に waste-inc2**。リポジトリ名のまま
7. **重さに乗るのは役を構成したカードだけ**。ジョーカーの枚数条件だけは「出した枚数」で数える
8. **累積系ジョーカーは、ランの間ずっと積み上がる**（便をまたいで保持）
9. **乗算補正は最後にまとめて掛け算で合成**。売上は1回の搬入ごとに切り捨てて合算
10. **同じジョーカーを複数所持できる**。プールは減らさず、同一ショップ内の重複だけ防ぐ
11. **不法投棄の噂はショップの特別枠**（価格0万円＋所持金を全額失う）
12. **中間処理場の株主の効果を利息2倍に変更**（最初の案は素の利息と同じで、何もしないカードになっていた）
